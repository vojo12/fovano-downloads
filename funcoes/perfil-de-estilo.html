Perfil de estilo · Local

Perfil de estilo: o seu jeito de editar, aplicado em pastas novas

O Fovano aprende como você edita no Lightroom e grava o mesmo visual no XMP das fotos novas.

Baixar para Windows ↓Como usar

As fotos das capturas estão desfocadas: são de um trabalho real e não temos autorização para publicá-las.

O problema

Cada trabalho novo começa do zero, mesmo quando você sempre edita do mesmo jeito.

Como o Fovano ajuda

Aprende com as suas fotos editadas

Importe uma pasta que você já editou no Lightroom (RAW com .xmp ou JPEG com o XMP dentro) e crie o perfil a partir de pelo menos 20 fotos editadas.

Exposição por cena

A exposição de cada foto nova é calculada para chegar ao brilho que você usa em cenas parecidas. O balanço de branco fica o da câmera.

Grava no XMP, dá para desfazer

A edição vai para o XMP; no Lightroom, é só ler os metadados. Fotos que você já editou ficam como estão, a não ser que você marque para substituir.

Passo a passo

  1. Importe uma pasta já editada no Lightroom.
  2. Aba Edição › Meu perfil de estilo… › criar o perfil.
  3. Abra a pasta nova, escolha o perfil e veja a prévia.
  4. Aplique. No Lightroom: Metadados › Ler metadados dos arquivos.
